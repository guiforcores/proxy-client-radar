A daily tracker of proxy clients built on mihomo, sing-box, Xray, V2Ray, Clash and their own cores. Open-source projects are measured by GitHub stars, store apps by US App Store / Google Play rating counts.

**Data as of: 2026-10-08** · [Web version (filters and sorting)](https://proxyclientradar.com/)
